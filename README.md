# Drácula: A História Nunca Contada

Jogo 2D de ação e plataforma com atmosfera gótica, desenvolvido como projeto original e pensado para controles móveis.

## Desenvolvimento

- Protótipo atual: HTML/JavaScript em `index.html`.
- Próxima etapa de produção: Godot Engine para o jogo 2D.
- Arte e animação: Pixelorama, LibreSprite ou Piskel.
- Mapas: Tiled ou LDtk, quando necessário.

Consulte [docs/FERRAMENTAS_E_FLUXO.md](docs/FERRAMENTAS_E_FLUXO.md) para os links oficiais, o fluxo de exportação e as regras de licenças.

## Princípios

- Manter o projeto separado de outros repositórios.
- Criar personagens, cenários, nomes e trilha originais.
- Preservar o protótipo atual até a nova versão estar testada.
