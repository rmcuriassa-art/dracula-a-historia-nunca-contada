# Projeto Godot — Drácula

Esta pasta contém a primeira estrutura nativa Godot 4 do jogo. O protótipo HTML na raiz permanece intacto.

## Abrir
1. Baixe/clone o repositório no computador.
2. Abra o Godot 4.
3. Importe o projeto selecionando esta pasta `godot/` (o arquivo `project.godot` está aqui).
4. Execute a cena principal.

## Controles
- A / D ou setas: mover
- Espaço / W / seta para cima: saltar
- Z ou X: atacar

## Arte
A cena usa temporariamente a folha SVG antiga em `../assets/hero.svg` como prova de integração. Ela é apenas um placeholder técnico; será substituída por uma spritesheet original desenhada e animada no Pixelorama/LibreSprite, com quadros separados e silhuetas mais expressivas.
